# 🏋️ Levels — High Performance Center

Sitio web profesional desarrollado para **Levels**, centro de alto rendimiento ubicado en **Tucumán, Argentina**.  
Una plataforma diseñada para transmitir excelencia, rendimiento y compromiso, facilitando la captación de nuevos atletas y la visualización de servicios, planes y sedes.

> **Más que un gimnasio, una filosofía de rendimiento integral.**

## 📌 Características Principales

- ✅ **Diseño Premium Dark Mode**  
  Estética oscura con acentos azul eléctrico, glassmorphism y gradientes que transmiten exclusividad deportiva.

- ✅ **Totalmente Responsive**  
  Adaptación fluida desde dispositivos móviles hasta pantallas de escritorio grandes. Hovers desactivados en dispositivos táctiles para evitar bugs visuales.

- ✅ **Arquitectura por Componentes**  
  Proyecto React modular con 11 componentes independientes y archivos CSS dedicados por cada uno.

- ✅ **Carrusel Infinito Interactivo**  
  Scroll automático de servicios con funcionalidad drag-to-scroll y pausa al interactuar.

- ✅ **Formulario Inteligente con WhatsApp**  
  Formulario de inscripción con validación que genera un mensaje pre-armado directo a WhatsApp del coach.

- ✅ **Botón Flotante de WhatsApp**  
  Integración persistente con animación de pulso y anillos expansivos para contacto inmediato.

- ✅ **Animaciones AOS**  
  Transiciones suaves al hacer scroll (fade, zoom, slide) para una experiencia dinámica y profesional.

- ✅ **Optimización de Rendimiento**  
  Carga ultrarrápida gracias a **Vite** y buenas prácticas en React.

## 🧠 Secciones del Sitio

### 🏠 Hero

Sección de impacto con logo animado (float), badge profesional, título con gradiente, avatares de comunidad y CTA directo a los planes.

### 🔬 El Método Levels

Tres pilares del enfoque 360°: **Evaluación** biomecánica, **Ejecución** con equipamiento de élite, y **Recuperación** con zona de recovery.

### 💎 Planes y Membresías

Tres opciones de membresía con diseño de tarjetas comparativas: **Mensual**, **Trimestral** (destacado como más popular) y **Semestral** con cuotas.

### 🕐 Horarios

Franja visual azul con horarios generales de lunes a viernes y detalle de sábados por sede.

### 🎯 Nuestros Ejes (Carrusel)

Carrusel infinito con las 4 áreas de excelencia: Entrenamiento Adaptativo, Recovery Deportiva, Nutrición Evolutiva y Rehabilitación.

### 📝 Inscripción

Formulario con campos requeridos (nombre, WhatsApp, membresía) que envía solicitud vía WhatsApp automáticamente.

### 📸 Galería

Grid asimétrico de instalaciones con animaciones hover de zoom y overlay azul (solo desktop).

### 📍 Sedes & Horarios

Tarjetas detalladas de **Sede Yerba Buena** y **Sede Centro** con direcciones, horarios específicos y botón de ubicación GPS.

| Tecnología            | Uso                                                                 |

| **React.js (v19)**    | Biblioteca principal de UI                                          |

| **AOS**               | Animaciones al hacer scroll                                         |
| **Font Awesome**      | Iconografía completa                                                |
| **Google Fonts**      | Tipografía Plus Jakarta Sans                                        |

## 🚀 Instalación y Uso Local

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/LautaroLeall/Levels-GYM.git
```

### 2️⃣ Instalar dependencias

```bash
npm install
```
